# Organização Scrum (planejamento inicial)

## Papéis

- **Product Owner:** a definir.
- **Scrum Master:** a definir.
- **Time de desenvolvimento:** a definir.

## Backlog

O Product Backlog inicial está descrito em [histórias de usuário](historias-usuario.md). Cada história pode ser transformada em uma GitHub Issue.

## Sprints sugeridas

| Sprint | Entregas previstas |
| --- | --- |
| 1 | Requisitos, histórias de usuário, regras de negócio e modelagem inicial. |
| 2 | Configuração do Django, PostgreSQL e autenticação. |
| 3 | Cadastro de espaços e consulta de disponibilidade. |
| 4 | Solicitação, aprovação e cancelamento de reservas. |
| 5 | Bloqueios, testes, integração e documentação final. |

## Fluxo sugerido no GitHub Projects

**Product Backlog → A fazer → Em andamento → Em revisão → Concluído**.

## Cerimônias

Planejamento da Sprint, reuniões rápidas de acompanhamento, revisão da entrega e retrospectiva. A duração das Sprints será definida pela equipe.
